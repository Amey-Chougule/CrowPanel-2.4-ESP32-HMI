# Example Projects

This folder contains example projects developed for the **Elecrow CrowPanel 2.4-inch ESP32 HMI**.

Each example demonstrates a specific feature or functionality of the display and ESP32 hardware.

## Purpose

These examples are intended to:

- Verify the functionality of the CrowPanel hardware
- Demonstrate display and peripheral features
- Provide simple reference implementations
- Serve as a starting point for developing custom HMI applications

## Hardware

**Elecrow CrowPanel 2.4-inch ESP32 HMI**

- ESP32-WROOM-32
- 2.4-inch 320×240 TFT display
- ILI9341 display controller
- Resistive touchscreen
- MicroSD card interface
- Wi-Fi and Bluetooth

## Software

The examples are developed using:

- Arduino IDE
- ESP32 Arduino Core
- Adafruit GFX Library
- Adafruit ILI9341 Library
- Other libraries as required by individual examples
